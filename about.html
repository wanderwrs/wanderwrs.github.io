搭建流程

  1. 静态站点，单文件体系。全站没有框架、没有构建器：每个页面都是一个自包含的 HTML 文件（内联 CSS / JS），直接部署在 GitHub Pages 用户站点 wanderwrs.github.io 上。
  2. 页面体系。主页承载 01-07 各板块，03 综合、04 作品与 06/07/08 等栏目使用同 CSS 的独立子页面，顶部导航以下拉折叠收纳。
  3. 发布管线。文件通过 GitHub REST API 逐个提交到 main 分支，GitHub Actions 自动构建，约一分钟后全网上线；每次更新都经过线上内容检查与浏览器实测。
  4. 备案。已在萌ICP备案中心完成备案：萌ICP备20261208号，全站页脚可见。
  5. 隐私。全站无 Cookie、无广告、无用户追踪脚本；留言板（规划中）仅存储访客主动提交的昵称与留言，审核通过后才会展示。

使用了哪些工具

Trae（AI IDE）
站点的开发环境。页面代码在 AI 辅助下生成与迭代，由站长提出需求、审校每一行代码并决定最终上线内容。自然语言协作 · 人机结对

「AIGC 图片作品」全部 21 幅作品的生成模型（千禧年风格 / 砼核幻想 / 雾季开学三个系列）。文生图 · 即梦系
satellite.js v5.0.0
U/V 卫星通讯页的 ISS 过境预报由它在浏览器内完成轨道递推，自托管于本站。MIT License · shashwatak/satellite.js
CelesTrak
ISS（NORAD 25544）TLE 轨道根数的数据来源，备用源为 TLE API。轨道数据 · 感谢 Dr. T.S. Kelso
jsDelivr CDN
AIGC 图片与静态资源的加速图床，回退链路指向本站 assets 目录。全球边缘缓存
Waline
留言板方案（部署中）：自托管客户端，数据存于私有仓库，留言经站长审核后展示。评论系统 · 规划上线
系统字体栈
PingFang SC / HarmonyOS Sans / Microsoft YaHei / SF Mono 等系统自带字体，零外部字体请求。无字体依赖
